# MagicEngine — history

The running log kept through November 13, 2026: decisions as they were made, coverage after each slice, and milestones. The current state is in the project status note and `docs/ARCHITECTURE.md`; this file is the record behind them.


Repo: https://github.com/chris-alexiuk/MagicEngine (private). Full design: docs/ARCHITECTURE.md in the repo.

## Decisions
- Browser client + authoritative game server (hidden info stays on the server). Humans only, no AI opponents for now.
- Commander first; 2–4 players. Multiplayer is free-for-all with the attack multiple players option (CR 903.2).
- Cards compiled from Scryfall Oracle Cards bulk data by a deterministic parser (no LLM). Unparsed rules lines are resolved manually in play, so every card is playable.
- Rules are codified as we go: the Comprehensive Rules (Sept 25, 2026) live in the repo as data; engine code and tests cite `CR x.y`; docs/rules/TRACE.md shows coverage and CI rejects citations of nonexistent rules.
- Keywords are compiled from their CR 702 definitions (`pnpm rules:keywords`), with the same grammar as card text.
- Images on demand from Scryfall's CDN with a service-worker LRU cache (default 250 MB budget).
- License still open: Forge's GPL-3.0 scripts would boost coverage but make the project GPL. To decide during milestone 3, now that our own grammar's reach is measurable.
- Parser is compositional (trigger/cost/subject + effect sentences + noun phrases), all-or-nothing per line. The compiler may only emit node tags the engine handles (`CORE_NODES` in packages/schema); tests and the data workflow check this, including abilities nested in tokens, emblems and granted quotes.
- Grading is honest: a keyword the engine doesn't apply counts as a manual line; granted static abilities the engine wouldn't apply stay unread; a granted keyword the engine can't apply (banding) leaves the line unread. A line whose meaning the engine would get wrong stays unread too (e.g. "that creature" inside a reflexive ability after "sacrifice another creature", a target "with mana value X" where nothing announces or counts X, a target card "from target player's graveyard", "If it's a Spirit, …" after the object was destroyed, "up to X target …, where X is …", a delayed "those creatures" that would be read again as cards in a graveyard, or an X in a triggered ability that nothing defines).
- Oct 30: Chris asked for a playable web app (deck builder, imports, play with only legal actions, official art). It's on main and hosted as a claude.ai artifact (no art there: the host blocks external images; art loads when run locally). Nov 6: back to the engine.
- Coverage work now follows the most-played Commander cards (the DB's EDHREC rank) as well as raw template counts.
